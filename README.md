
# 从入门到精通的全链路学习资源地图

---

## 📚 书籍推荐（按学习顺序）

| 阶段 | 书名 | 作者 | 适合人群 |
| ------ | ------ | ------ | ---------- |
| 入门 | 《MySQL必知必会》 | Ben Forta | 零基础快速上手，简明扼要 |
| 进阶 | 《高性能MySQL》（第4版） | Baron Schwartz等 | 有一定基础，主攻性能优化 |
| 原理 | 《MySQL技术内幕：InnoDB存储引擎》 | 姜承尧 | 想深入理解事务、锁、日志底层 |
| 综合 | 《深入浅出MySQL》 | 姜承尧 | 全面覆盖开发、优化与管理维护 |
| 架构 | 《MySQL实战45讲》 | 丁奇 | 想深入理解架构、运维、备份恢复 |
| 原理 | 《MySQL 是怎样运行的：从根儿上理解 MySQL》 | 李昊轩 | 想深入理解架构、运维、备份恢复 | <https://relph1119.github.io/mysql-learning-notes/#/>

> **你的重点**：跳过《MySQL必知必会》，直接啃《高性能MySQL》+《MySQL技术内幕：InnoDB存储引擎》。这两本是你从"会用"到"精通"的关键。

### 🎬 视频教程（免费优质资源）

**中文视频（B站为主）：**

1. **尚硅谷《MySQL数据库教程天花板》**（宋红康）—— 零基础入门首选，讲得细、案例多
2. **动力节点《MySQL进阶教程》** —— 适合你已经入门后，专门学索引、事务、锁机制
3. **传智播客《MySQL高级课程》** —— 覆盖视图、存储过程、索引优化、SQL调优，适合全栈方向
4. **极客时间《MySQL实战45讲》**（丁奇）—— 付费课程，但质量极高，专门讲原理和实战

**英文视频：**

- **Coursera《Advanced MySQL Topics》**（Meta认证课程）—— 覆盖存储过程、CTE、JSON、触发器、查询优化，有实战项目

---

### 📖 官方文档（必看）

- **MySQL 8.0 Reference Manual**（官方文档）—— 最权威，遇到具体函数、参数、配置问题直接查
- 重点章节：
  - `Optimization`（优化指南）
  - `InnoDB Storage Engine`（存储引擎原理）
  - `Replication`（主从复制）

---

### 💻 刷题与实战

1. **LeetCode 数据库板块** —— 从简单题开始（如175、181题），逐步挑战中等难度
2. **牛客网 SQL 专项练习** —— 国内面试高频题
3. **实战项目建议**：在你的NestJS项目中，刻意设计复杂查询场景（如多表JOIN、分页、聚合统计），然后用 `EXPLAIN` 分析执行计划，手动优化慢SQL

### 🗺️ 你的专属学习路径（结合NestJS背景）

| 阶段 | 时间 | 核心内容 | 推荐资源 |
| ------ | ------ | ---------- | ---------- |
| **第一阶段：SQL深化** | 2-3周 | 复杂JOIN、子查询、窗口函数、CTE、聚合统计 | 《高性能MySQL》前6章 + B站动力节点进阶教程 |
| **第二阶段：索引与优化** | 3-4周 | B+树原理、EXPLAIN分析、索引失效场景、慢查询日志 | 《高性能MySQL》索引章节 + 极客时间《MySQL实战45讲》 |
| **第三阶段：事务与锁** | 2-3周 | ACID、隔离级别、MVCC、行锁/间隙锁/Next-Key Lock | 《MySQL技术内幕：InnoDB存储引擎》 |
| **第四阶段：架构与运维** | 持续 | 主从复制、读写分离、分库分表、备份恢复、Docker部署 | 官方文档 + 传智播客高级课程 |

---

### 💡 给你的建议

你已经有NestJS项目经验，**不要从零看入门视频**，直接：

1. **买《高性能MySQL》+《MySQL技术内幕：InnoDB存储引擎》**，边看边在你的NestJS项目里实操
2. **打开慢查询日志**，把你项目里的SQL一条条用 `EXPLAIN` 分析，找出全表扫描、文件排序的问题
3. **刷LeetCode数据库题**，每天2-3道，巩固SQL思维
4. **看极客时间《MySQL实战45讲》**，丁奇讲得非常透彻，适合你这种有项目经验的人
